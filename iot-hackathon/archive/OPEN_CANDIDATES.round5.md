## N031 BorrowedEar

**작업:** 아래층에서 잠시 측정한 데이터로 내 걸음의 전달 소음을 학습한 뒤, 아래층 장치를 철거하고 위층 사용자만 착용형 센서를 쓰는 개인 피드백 장치.

**바뀌는 사용 흐름:** 이웃의 집에 상시 마이크를 놓거나 매번 소음을 물어볼 필요를 줄인다. 학습 때만 두 위치를 연결하고 이후에는 발의 접촉 힘·IMU 신호로 해당 환경의 상대적 전달 영향을 추정한다. 일반 소음 알림 N030과 달리 수신부를 없앤 뒤 사용할 수 있어야 가치가 생긴다.

**물리 루프:** 깔창의 여러 압력 지점과 발목 IMU → 보드의 시계열 추정 → 착용 진동 → 사용자가 다음 걸음을 조절 → 다음 접촉 다시 측정. 교정 때는 수신실 마이크의 시간 정렬된 이벤트를 라벨로 쓴다. 카메라만으로는 발바닥 접촉 이력과 다른 방의 실제 전달량을 얻을 수 없다.

**구현 범위 초안:** 한 사용자·한 이동 구역·두 신발/보행 조건. 신발에 작은 센서 노드를 두고 VENTUNO Q는 근처 허브로 사용한다. 큰 보드를 신발 안에 넣는 설계가 아니다. 법정 소음 판정이나 이웃의 불쾌감 추정은 목표에 없다.

**강한 비교군:** 접촉 피크 임계값, 구역/신발별 선형 회귀, 상층 바닥 진동에서 하층 소음으로의 선형 전달 모델. 단순한 피크 알림만 이겨서는 통과가 아니다.

**이미 확인한 근거와 한계:**
- [보행 변경과 바닥 충격 연구](https://journals.sagepub.com/doi/abs/10.1177/1071181321651153)는 보행 변화가 충격 지표를 바꾼다는 근거다. 본 장치의 예측 정확도를 입증한 자료는 아니다. 출판사 검색 초록은 확인했으나 직접 열람은 타임아웃이었다.
- [발소리와 지면 반력 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC9787899/)는 두 신호의 관련성을 다룬다. 소리→힘의 결과를 힘→다른 방의 소리 정확도로 바꿔 주장하지 않는다.
- [이웃 간 소음 AI 특허](https://patents.google.com/patent/KR20220013498A/ko)는 가까운 선행이다. 상시 두 장치의 상태 교환과 임시 교정 후 수신부 철거는 다른 흐름이나, 추가 선행 확인이 필요하다.

**아직 해결하지 못한 것:** 동일 구역에서 접촉 신호만으로 전달량을 충분히 예측할 수 있는가. 단순 전달 모델보다 학습의 이득이 있는가. 실제 두 공간에서 검증해야 하며, 책상판을 두드리는 모형으로 주거 환경 소음 개선을 주장하면 안 된다. 물리 변수가 많다는 말만으로 AI가 필요하다고 판정하지 않는다.

**다음 검토:** 수신부 철거 후 예측하는 기존 제품·논문을 추가 확인하고, 최소 관측량과 강한 비교군의 성능 한계를 문헌에서 분리한다. 남은 핵심이 새로운 물리 상관의 발견에 의존하면 탈락시킨다.

## N034 WindNegotiator

**작업:** 사용자가 실제 돛을 바꾸고, AI가 실제 팬으로 바람을 바꿔 맞서는 탁상 경기.

**차이:** F09의 한 축 광원 조작, F10의 준비된 세 상태 추리는 그대로 재사용하지 않는다. 참가자가 만든 물체의 운동 응답이 플레이 중 바뀌고, 장치가 그것을 다시 학습하는 것이 핵심이어야 한다.

**부품 초안:** 얕은 수조, 방수 선체 두 개, 바꿔 끼우는 돛, 팬 세 개와 PWM 구동, 상부 카메라. 보드는 실제 팬의 출력과 정지 상태를 제어한다. 수조 영상만 화면에서 분석하는 데모는 목표가 아니다.

**AI 역할 초안:** 위치·속도·돛 방향·팬 명령에서 짧은 미래 움직임을 예측하는 소형 동역학 모델. 현재 위치만 추종하는 제어, 선형 응답 모델, 무작위/고정 바람을 비교군으로 둔다. 처음부터 대규모 강화학습이나 유체 시뮬레이터를 요구하지 않는다.

**아직 해결하지 못한 것:** 참가자가 반복해서 내리는 의미 있는 선택과 AI의 역할을 명료하게 규정하지 못했다. 팬으로 배가 움직이는 것을 시연하는 것만으로는 게임의 가치나 모델 필요성이 생기지 않는다. 기존 자동 항해 연구와 구별된다는 이유만으로 새 경기의 매력을 인정하지 않는다.

**다음 검토:** 한 경기의 입력·금지 행동·승리 조건을 먼저 고정한다. 정적인 돛 성능 대결에 그치거나 AI가 단순 위치 제어로 대체되면 탈락. 기존 인터랙티브 전시·팬 구동 게임을 넓은 기능 검색으로 추가 대조한다.

## N038 KnotKeeper

**작업:** 한 손으로 매듭 공예를 할 때 놓아야 하는 실의 장력을 장치가 이어받고, 다시 쓸 실을 돌려주는 받침.

**차이:** N037의 막연한 제본 작업 추종은 탈락시켰다. 이 변형은 손 하나가 여러 실을 번갈아 붙잡아야 하는 구체적인 지지 인계에 한정한다. N035처럼 실 엉킴을 로봇 기구로 모두 풀려 하지 않는다.

**부품 초안:** 압력/장력 감지 클램프 네 개, 낮은 힘의 서보, 카메라, VENTUNO Q. 실제 실을 지탱하는 부분이 없으면 한 손 작업이라는 목적을 수행하지 못한다.

**강한 비교군:** 고정 매듭판, 수동 집게, 발 페달/버튼으로 클램프 선택, 힘 임계값을 사용하는 자동 해제, 정해진 매듭 순서의 상태 머신. 매듭 순서대로 집게만 바뀌는 장치는 AI 프로젝트로 통과시키지 않는다.

**핵심 반론:** 당김을 감지해 잠그고 풀기만 하면 힘 센서 규칙으로 충분할 수 있다. 반대로 숨은 매듭 위상이나 사용자의 다음 의도를 카메라가 읽어야 한다면 관측 불가능성과 데이터 부담이 커진다. 손을 놓은 뒤에 인식해서는 지지 인계에 늦을 수 있다.

**다음 검토:** 필요한 인계를 관측 가능한 접촉/움직임 사건으로 정의하고, 그중 무엇에 학습이 필요한지 분리한다. 수술용 매듭 로봇/가상 제약 연구는 기반 선행이지만 그대로 같은 사용자 작업이라고 판정하지 않는다. 개인 공예용 보조기와 명확히 다른 사용 흐름이 없으면 제외한다.

## 공통 보드 조건

[VENTUNO Q 공식 소개](https://www.arduino.cc/product-ventuno-q)에서 Linux 측 추론과 STM32H5 측 물리 제어를 결합하는 구성을 확인했다. 특정 모델의 NPU 변환이나 광고상의 응답 수치가 곧 이 후보의 실제 성능이라는 뜻은 아니다. 소형 CPU 추론을 기본 경로로 잡고, 모델/센서 부품 확보와 실제 루프 지연은 선정 이후 확인해야 한다.
