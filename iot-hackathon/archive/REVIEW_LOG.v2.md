## v2 — 적대적 리뷰 반영

기존의 ‘10개 설계 검토 통과’와 추천 순위를 철회한다. 위험을 문서에 쓴 것과 위험을 해결한 것을 구분하지 못한 판단이었다.

| 단계 | 결과 | 증거의 종류 |
|---|---|---|
| 리뷰 대조 | 공통 지적 4개와 후보별 지적 10개를 대응 문서에 반영 | 문서 검토 |
| 구조 변경 | SeamBack → ResumeStitch, Quantization Cliff → Live Acceptance | 설계 변경; 실물 실험 전 |
| 예비안 변경 | Physical CI → ResetCheck | 실제 운영 사례 확보 전 보류 |
| 나머지 7개 | 현재 추천 제외; 변경 검토와 재개 조건 기록 | 설계 검토 및 일부 추가 선행 조사 |
| 포장·그리퍼 대안 | 운반 제어·파손 전 제어도 가까운 선행 연구로 제외 | 저자·논문 공개 자료 |
| 현재 우선순위 | ResumeStitch → 조건부 Live Acceptance | 사전 실험 순위; 출품 확정 아님 |

신규성 검색에서 결과가 없다는 이유로 통과시키지 않는다. 작은 데모 성공이 실제 사용자 과제의 개선으로 이어지는지, 가장 단순한 대안보다 나은지, 물리 현상이 반복되는지 확인한 후에만 다음 판정을 한다. AI 기여와 사용자 효용은 별도 축이다.

보드 실행, 부품 실험, 학습, 사용자 검증은 이번 문서 수정에서 수행하지 않았다. 제안한 통과 수치들은 실험 전 선택 기준이며 실측 성과가 아니다. 따라서 원래 목표였던 좋은 후보 10개 확보를 현재 달성 상태로 표시하지 않는다.
