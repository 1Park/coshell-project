# 적대적 리뷰 대응 — 2026-10-04

대상: [ADVERSARIAL_REVIEW.md](ADVERSARIAL_REVIEW.md). 수정 결과: [IDEAS.md](IDEAS.md). 이전 설계: [v1](archive/IDEAS.v1.md).

리뷰 원문은 변경하지 않았다. 기존 추천 순위와 ‘10개 설계 검토 통과’를 철회한다. 이번 작업은 문헌 확인과 설계 수정이며, 물리적 성공이나 사용자 효과를 검증한 작업이 아니다.

## 공통 지적에 대한 변경

| 지적 | 실제 변경 | 설계만으로 해결되지 않는 부분 |
|---|---|---|
| 기존 사례와 다른 설명만 있고 사용자 가치가 약함 | 자수는 전체 재개 시간, 비전 검사는 사람의 설치 확인 시간, 리셋 검사는 준비 누락에 의한 중단을 결과 지표로 변경 | 사람이 실제로 시간을 아끼는지 측정 필요 |
| 단순 센서·영상 처리·상태 머신으로 충분함 | 각 안에 가장 강한 비학습 비교군을 명시. 모델을 빼도 같으면 AI 트랙 후보에서 내림 | 동일 입력·동일 조건의 비교 미실시 |
| 쉬운 데모가 실제 문제의 어려움을 없앰 | 자수는 실제 Aida 천, 비전 검사는 실제 재장착과 보류 샘플, 리셋은 실제 운영에서 발생한 누락으로 한정 | 천 판독·광학 변화·리셋 누락 현상은 관측 필요 |
| 기구→데이터→모델→시연 의존성을 인시로 감춤 | 촬영·단순 대안부터 확인하는 순차 계획, 초기 중단 시점, 모델/기구 동시 신규 개발 회피 | 카메라 확보, 보드 환경, 작업자 모집 등 미확인 |
| 위험을 적은 것을 해결로 판정함 | 상태를 ‘우선 검증 / 예비 / 추천 제외’로 변경. 출품 확정 없음 | 최종 재심사에는 실제 증거가 필요 |

## 후보별로 무엇을 바꿨고 왜 남기거나 버렸는가

### 1. Quantization Cliff → Live Acceptance

- **수용한 반론:** 양자화 불일치 발견에 시연 전체가 걸려 있고, 저장 이미지 재생보다 실물 시험이 왜 필요한지 약했다.
- **핵심 변경:** 양자화 비교를 삭제. 장치를 다른 곳에 재설치한 직후, 현재 카메라·조명 경로를 포함한 실물 검사로 변경. 자동 회전대도 삭제하고 수동 트레이와 조명 제어만 남겼다.
- **설계에서 해결:** 드문 FP32/INT8 차이를 기다릴 필요가 없다. 과거 이미지가 현재 광학 상태를 검사하지 못한다는 차이는 명확하다.
- **미해결:** 재설치 실패와 자동 복구가 의미 있게 반복되는지, 사람의 수동 실물 검사보다 빠른지, 기존 커미셔닝 도구와 차이가 충분한지. 단순 화질 검사도 강한 비교 대상이다.
- **판정:** 두 번째 검증 후보. 기존 작동 모델이 없으면 착수하지 않는다.

### 2. Physical CI → ResetCheck

- **수용한 반론:** 3단계 부분 재시험의 절약은 작고, 실패 지점 찾기는 센서·상태 머신으로 충분하다.
- **핵심 변경:** 연쇄 장치의 고장 추론을 버리고, 반복 시연 전에 덜 리셋한 소품을 확인하는 과제로 변경.
- **설계에서 해결:** ‘전체 시험보다 몇 초 빠름’이라는 약한 효용과 복잡한 중간 투입 기구를 삭제했다.
- **미해결:** 사진 체크리스트·스위치·기준 영상 차이보다 나을 이유가 부족하다. 반복 체험 10회에서 실제 누락과 복구 비용부터 관찰해야 한다.
- **판정:** 예비. 현실 사용처를 확보하기 전에는 제작하지 않는다.

### 3. SeamBack → ResumeStitch

- **수용한 반론:** 뒷면·실 연결 이력이 보이지 않고, 즉시 경고와 복잡한 undo의 가치가 충돌하며, 정상 작업을 계속 끊는다.
- **핵심 변경:** 모든 땀의 추적·경고·복구를 삭제. 중단 후 한 번 촬영해 완료 상태를 도안과 맞추고 재개를 돕는다. 큰 플라스틱 격자 대신 실제 천을 사용한다.
- **설계에서 해결:** 과거 작업 순서나 뒷면을 알 필요가 없고, 매 땀마다 손을 떼지 않는다. ‘마지막 위치’ 대신 ‘다음 작업 가능한 칸’을 안내한다.
- **미해결:** 실제 천에서의 정확도, 불확실 칸 확인 비용, 잘 관리된 앱 기록보다 편리한지, 스마트폰 대신 보드 장치가 필요한지.
- **판정:** 첫 번째 검증 후보. 남은 위험이 비교적 작고 빠른 실험으로 드러난다는 설계 판단이다.

### 4. TouchDebt → 추천 제외

- 센서로 접촉을 확정하면 AI가 주변 기능이고, 영상에 맡기면 추정 오류가 전파된다는 반론을 수용한다.
- 검토한 수정은 접촉 그래프 대신 형광 잔류물을 직접 보는 방식이었다. 하지만 이는 원래의 숨은 전파 추론을 제거하면서 단순 영상 임계값·직접 관찰과 경쟁하게 된다. 교육 효과도 따로 입증해야 한다.
- 이 수정안을 신규 발명이나 개선된 AI안으로 채택하지 않았다. 재개하려면 동일 교육 시간의 단순 관찰 방식보다 학습 결과가 나아진다는 근거가 필요하다. 실제 오염 여부 판정으로 확장하지 않는다.

### 5. TugMap → 추천 제외

- 짧고 느슨한 배선만 남기면 사용자가 이 도구를 필요로 하는 환경을 없앤다는 반론을 수용한다.
- 더 큰 흔들림·더 단순한 배선은 해결책으로 인정하지 않는다. 먼저 실제 케이블 묶음에서 한 가닥 자극의 양끝 대응이 구분되는지, 사람이 흔드는 방법보다 나은지 확인해야 한다.
- 이는 모델 문제가 아니라 관측 가능한 신호의 문제다. 신호가 식별되지 않으면 더 큰 모델로 넘어가지 않는다.

### 6. PackProbe → 운반 제어로 변경 검토 후 제외

- 포장 속 상대 움직임 감소가 배송 품질을 뜻하지 않는다는 반론을 수용한다.
- 대안은 포장 품질 추정을 없애고, 실제 움직이는 트레이에서 물체가 미끄러지지 않도록 가속을 조정하는 것이었다. 여기서는 미끄러짐 자체가 사용자 결과여서 원래의 대리지표 문제는 줄어든다.
- 그러나 [비파지 운반 제어 연구](https://arxiv.org/abs/2306.14212)가 이미 고체·액체 운반의 운동 제어를 다룬다. 새 선형 이동 기구도 필요하다. 사용자 기준인 기존 프로젝트 중복을 해소하지 못하므로 이 대안도 채택하지 않는다.
- 원안은 실제 포장 결과의 평가 없이 부활시키지 않는다. 트레이를 기울인 것만으로 실제 운반의 가속 제어를 검증했다고 처리하지 않는다.

### 7. PatchMatch → 추천 제외

- 곡선 유사성이 수선 결과 개선으로 이어지는지와 측정 장비 신뢰성을 동시에 해결해야 한다는 반론을 수용한다.
- 대안은 실제 수선 샘플의 반복 변형 후 벌어짐·손상을 비교하는 것이었다. 그러나 그 비교를 하려면 먼저 수선 샘플·반복 하중·평가 기준을 준비해야 한다. 일정 위험이 사라지지 않는다.
- 안정된 기존 시험 장비와 수선 샘플이 없는 현재 조건에서 해커톤 우선안으로 삼지 않는다. 센서 수를 줄여도 빠진 정보가 모델로 자동 복원되지는 않는다.

### 8. ReGrip → 강한 비교군 추가 후 제외

- 고정 힘만 비교하면 자동 교정의 성과를 과대평가한다는 반론을 수용한다. 동일 센서·구동기를 사용하는 단계적 닫기/미끄러짐 확인 제어를 기본 비교군으로 바꿨다.
- 대안인 ‘미끄러짐과 파손 사이의 힘을 실시간 조정’도 [TactileReflex](https://shayfeng.github.io/TactileReflex/) 및 [FORTE](https://merge-lab.github.io/FORTE/)와 매우 가깝다. 직접 조사한 기존 저자 프로젝트다.
- 임시 손가락 소재를 바꾸는 것만으로 충분한 차별성을 주장하지 않는다. 이미 조립된 그리퍼와 강한 비교 결과가 없으면 재개하지 않는다.

### 9. Shadow Bargain → 이번 트랙 추천 제외

- 한 축 광원은 단순 순회 탐색으로 충분할 수 있고, AI를 위해 광학 난도를 추가하는 것은 잘못된 순서라는 반론을 수용한다.
- 협동 놀이만 남기면 더 간단히 만들 수 있지만 온디바이스 AI의 역할이 사라진다. 게임으로서 가능성과 이번 트랙의 적합성을 분리한다.
- 복잡한 소품을 추가해 모델을 강제로 필요하게 만들지 않는다. 실제 플레이테스트에서 협동 경험이 확인되고 단순 제어의 한계가 드러나기 전에는 재추천하지 않는다.

### 10. BlackBox Duel → 추천 제외

- 3가지 바닥·4가지 행동이면 고정 실험 순서나 작은 결정 트리가 충분하다는 반론을 수용한다.
- 같은 실험 예산의 최선 고정 순서·결정 트리를 비교군으로 추가했다. 조건을 늘려서만 AI가 이기게 만들면 데이터·기구 부담도 같이 커진다.
- 재개하려면 학습에 쓰지 않은 실제 물리 조건에서 더 적은 실험으로 더 나은 예측을 보여야 한다. 현재는 그 증거도 관객이 느낄 추론의 매력도 없다. 추론 게임이라는 설명만 다듬어 살리지 않는다.

## 재심사 때 필요한 기록

각 실험은 `후보 / 조건 / 독립 시행 번호 / 비교 방법 / 예측 / 실제 결과 / 사람 개입 시간 / 전체 시간 / 실패·확인 필요 / 원본 파일`을 남긴다. 모델·카메라 설정·데이터 분할도 같이 보관한다.

세 증거가 모두 필요하다: **가장 단순한 대안을 이긴 장면, 반복된 물리 현상, 실제 사용자 과제의 개선.** 시연 영상 하나나 인접 프레임 수백 장은 독립 반복 실험의 대체물이 아니다. 계획된 목표 수치를 측정 결과 칸에 미리 쓰지 않는다.

이번 수정은 기존 10개에 대한 재심사와 구조 변경까지다. 새로 검증된 10개를 확보했다는 의미는 아니다. 남긴 두 안도 실험에서 탈락할 수 있다.
