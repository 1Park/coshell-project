## 핵심 변경

N060은 입이나 머리로 붓을 쓰는 사람의 다음 작업 영역을 추측해 이젤을 옮기는 안이었다. 그 의도를 알 수 없고, 명시적 선택을 사용하면 기존 전동 이젤과 가까워 탈락했다.

StillPaper는 사용자가 무엇을 그릴지 선택하지 않는다. 도구 끝의 짧은 주기 움직임을 측정하고, 실제 종이를 같은 방향으로 조금 움직여 종이에 남는 상대적 흔들림을 줄이는 구상이다. 팔이나 펜을 구동하는 대신 작업 면을 움직여 사용자가 자기 도구를 쓸 수 있게 하는 것이 목적이다. 이 차이가 실제 사용자 이득인지, 기존 떨림 보상 장치의 위치만 바꾼 것인지 아직 검토 중이다.

종이를 반대 방향으로 움직이면 상대 흔들림이 커진다. 도구 위치를 p, 종이 위치를 s라 하면 잉크의 상대 위치는 p−s다. 보상해야 할 도구 운동 성분과 **같은 방향**의 종이 운동이 필요하다.

## 필요한 물리 루프

도구의 가벼운 IMU와 위치 마커, 빠른 카메라 또는 좌표 입력 장치 → 떨림 대역 신호와 짧은 미래 움직임 예측 → MCU의 XY 구동 → 실제 종이 위치/도구 위치 재측정.

작은 XY 벨트 스테이지에 A6 판을 올리고, 종이는 고정한다. MCU는 홈·이동 범위·속도·통신 타임아웃을 처리하고 MPU는 예측 모델을 실행한다. 카메라 앱만으로 종이에 이미 남을 선의 상대 운동을 바꿀 수 없다. 다른 컴퓨터와 같은 구동기를 조합해 구현할 수 있다는 점은 인정한다.

일반 30fps 카메라가 충분하다고 가정하지 않는다. 센싱→통신→예측→모터 응답의 전체 지연을 측정해야 한다. 또한 종이를 움직일 때 펜과의 마찰이 사람의 도구 운동에도 영향을 주므로, 독립된 두 위치 신호만 더하고 빼는 이상적 계산이 실제 접촉을 완전히 설명하지 못한다.

## AI를 붙일 이유와 강한 비교군

지연된 움직임을 그대로 따라가면 보상이 오히려 흔들림을 키울 수 있다. 모델의 후보 역할은 짧은 미래의 위상과 진폭을 예측하여 물리 구동 지연을 보상하는 것이다. 어떤 선을 그릴 의도였는지 생성 모델로 복원하는 기능은 넣지 않는다.

비교군은 무보상, 지연 신호 그대로 추종, 일정 속도 외삽, 학습된 선형 AR, 적응 주파수/WFLC 계열 예측이다. 고정 저역 통과 필터만 비교하여 신경망이 필요하다고 주장하지 않는다.

[2022년 LSTM 떨림 예측 연구](https://pubmed.ncbi.nlm.nih.gov/36170410/)는 실제 손목 굴곡/신전 신호에서 미래 위상과 진폭 예측을 다룬다. 전기 자극 타이밍에 대한 연구이며, 종이 스테이지의 지연·공간 오차·자발 운동 보존을 입증한 것은 아니다. 해당 연구 수치를 이 장치의 성능으로 옮기지 않는다.

지금도 남는 핵심 문제는 빠른 자발적 획과 억제할 흔들림의 구별이다. 주파수 대역으로 분리한 신호는 실제 의도의 정답이 아니다. 느린 선에서만 작동한다고 제한할 때도 사용자가 원하는 실제 그림 작업이 남는지 확인해야 한다.

## 데이터와 검토 실험

[UCI의 공개 그래픽 태블릿 기록](https://archive.ics.uci.edu/dataset/395/parkinson%2B)은 좌표·시간·펜 관련 신호를 제공하며 CC BY 4.0이다. 작은 예측 모델과 선형 비교군의 오프라인 비교를 시작할 수 있는 자료다. 데이터셋의 건강 상태 라벨을 예측하거나 새 의료 진단을 만드는 것이 목적이 아니다.

피험자 단위로 학습/검증/평가를 나누고, 실제 센서 타임스탬프의 간격과 빠진 구간을 먼저 확인한다. 미래 값을 사용한 양방향 필터를 실시간 모델 입력에 쓰지 않는다. 인접 윈도우를 무작위로 나눠 정확도를 부풀리지 않는다.

이 데이터는 종이가 움직이지 않는 기존 태블릿에서 수집됐다. 따라서 예측 결과가 좋아도 상호작용하는 기구의 폐루프 결과나 사용자의 만족을 검증한 것은 아니다. 특히 떨림 분류/중증도 예측 논문을 미래 좌표 예측의 근거로 혼동하지 않는다.

## 순차 구현과 중단 조건

1. 오프라인 데이터 타이밍/예측 비교와 실제 부품의 목표 지연 예산을 확인한다.
2. 빈 종이 스테이지에서 작은 반복 변위의 실제 지연·진폭·방향을 측정한다. 1Hz의 쉬운 동작만으로 빠른 보상을 입증하지 않는다.
3. 일정한 펜 움직임과 알려진 추가 흔들림을 주는 시험에서 실제 잉크 선의 오차를 비교한다.
4. 마지막에 자유로운 도구 움직임과 접촉 마찰 조건을 넣는다. 건강한 사람이 일부러 손을 흔든 결과를 환자의 실제 사용 효과로 표현하지 않는다.

기성 스테이지가 있어도 고속 위치 측정, 예측, 모터 지연, 마찰의 순차 통합이 남는다. 이 경로가 행사 범위에 들어가는지 아직 판정하지 않았으므로 공수 합계만으로 PASS 처리하지 않는다. 작은 예측기가 선형/적응 예측기보다 도움이 없거나 자발적 획을 손상시키면 AI 해커톤 후보에서 제외한다.
