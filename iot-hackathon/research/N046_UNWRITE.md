# N046 Unwrite — 그림의 뜻을 지우는 로봇

2026-10-04 · **VALID — 설계 검토 통과**. 제작·모델 성능·사용자 재미는 실측 전이다.

## 게임과 달라지는 경험

그리는 사람에게만 ‘자전거’ 같은 단어를 보여준다. 10초 동안 작은 화이트보드에 그리면, AI는 **정해진 작은 면적 세 곳만** 실제 지우개로 지울 수 있다. 그림을 못 보던 팀원에게 결과를 공개한다. 못 맞히면 그리는 사람이 남은 그림에 다시 단서를 추가한다. 세 번 안에 전달하면 인간 팀 승리다.

AI는 단어를 알고 있다. 많이 칠한 곳을 지우는 대신 ‘이 부분이 없어지면 자전거로 알아보기 어려워질 것’이라는 자기 모델의 예측으로 지운다. 사람은 동작·배경·부분의 중복 같은 다른 표현 전략을 쓴다. 로봇의 약점을 이용하는 것도 게임의 일부다. 단순 AI 그림 맞히기와 달리 상대가 **원본을 실제로 훼손하고**, 사용자는 그 흔적을 받아 다시 그린다.

무작위 방해가 있는 낙서 장난감으로 끝내지 않고, 소거 예산 안에서 전달 단서를 지키고 복구하는 팀 게임으로 고정한다. 글자와 숫자로 단어를 쓰는 행동은 금지한다. 승패는 사람이 실제로 맞혔는지로 정하며 모델의 신뢰도를 인간의 이해도라고 주장하지 않는다.

## 보드와 AI의 역할

카메라 → 보드에서 그림 정규화·소형 스케치 분류 → 지울 영역 후보를 가상으로 가려 재분류 → 목표 단어의 점수를 가장 낮추는 영역 선택 → MCU의 XY 모터·지우개 접촉 제어 → 실제로 지워졌는지 재촬영.

데스크탑+카메라만으로는 실제 잉크를 지울 수 없다. 별도 제어기·드라이버·모터를 붙인 데스크탑이라면 같은 구조를 만들 수 있다는 점은 인정한다. 작은 크기나 오프라인만을 Arduino의 존재 이유로 삼지 않는다. 화면 게임으로 각색하는 것은 가능하지만, 원안의 물리 소거와 재작업을 제공하지는 않는다.

AI는 그려진 물체와 그 부분의 분류 기여도를 추정한다. MCU 모터 제어와 경로 탐색에는 규칙을 쓴다. **비교군은 같은 소거 면적/횟수의 무작위 선택, 잉크 밀도 최대 영역, 윤곽 연결을 가장 많이 끊는 영역**이다. 모델 기반 공격은 선의 양이나 연결 수가 아니라 형태의 의미에 의존한다. 모델의 판단이 사람과 다를 때는 게임 상대의 실수이며, 사람이 그림을 못 알아볼 것이라고 보증하지 않는다.

## 실제 구현 범위

- A5 정도의 작은 화이트보드, 모서리 마커, USB 카메라, 범용 소형 XY 플로터 키트, 스프링으로 눌리는 펠트 팁과 승강 서보, 끝점 스위치, 별도 모터 전원, VENTUNO Q 한 대.
- **플로터 키트 확보가 전제**다. 행사 제공 액세서리에 포함된다고 가정하지 않는다. 판재부터 새 XY 기구를 가공하는 일정은 이 안에 포함하지 않는다.
- 처음에는 공개 데이터가 있는 20개 정도의 구체 명사, 한 색 마커, 실제 자유 손그림. 미리 인쇄한 그림만 놓고 작동시키지 않는다.
- [Quick, Draw! 공개 데이터](https://github.com/googlecreativelab/quickdraw-dataset)를 이용해 작은 CNN을 학습한다. 실제 보드 사진으로 원근·배경·선 두께의 차이를 확인한다. 특정 타인의 저장 가중치가 반드시 배포 가능한 형식이라고 가정하지 않는다.
- 한 번에 지울 후보 영역 수를 제한하고 작은 이미지에서 배치 추론한다. 거대 비전언어 모델이나 생성형 이미지 모델을 매 턴 실행할 필요는 없다.
- 그리기/소거를 명시적으로 번갈아 한다. 접촉이 있는 기구를 움직이면서 동시에 손 위치를 AI가 완벽히 추적해야 한다는 의존성을 없앤다. 시작 버튼과 덮개/인터록으로 이동을 허용한다.

## 임계 경로와 직접 평가

견적: 기성 키트 조립·기본 이동 3–4시간 → 마커 좌표 교정과 반복 소거 2–3시간 → 분류 모델 및 실제 사진 입력 확인 3–4시간 → 후보 소거 선택·게임 통합 3–4시간 → 실제 새 그림으로 비교 2–3시간. 모델의 공개 데이터 학습은 기구 조립과 독립적으로 진행할 수 있지만, 카메라 입력 확인과 통합 검증은 기구 이후다.

첫 기구 검사는 1–2cm 영역을 반복해서 지우되 옆의 선을 과도하게 지우지 않는가다. 위치 오차와 팁 접촉을 이 단계에서 확인한다. 불안정하면 큰 범용 로봇팔을 추가하지 않고 이 구현을 중단한다. 모델 검사는 준비한 사진이 아니라 참가자가 새로 그린 그림으로 한다. 사진 정규화 후에도 범주의 차이를 읽지 못하면 같은 그림을 암기시키는 시연으로 대체하지 않는다.

직접 지표는 팀원이 맞히는 데 필요한 복구 라운드 수, 완료된 경기 수, 소거 면적, 소거 오차와 한 턴 소요 시간이다. 모델 점수 하락은 진단 지표일 뿐 재미나 인간의 인식 저하에 대한 대리 증거가 아니다.

## 가까운 구현을 피한 지점

- [UnsTable](https://arxiv.org/abs/2402.03691)은 종이를 움직여 그리기를 방해하는 적대적 로봇 책상이다. 방해하는 로봇 자체는 새롭지 않다. 본 안의 핵심은 이미 그린 결과의 의미를 읽고 제한된 소거로 **사람 간 전달**을 방해한다는 것이다.
- [PICaSo](https://www.idoll.love/en/our-research/picaso-collaborative-art-creation)는 사람 지시에 따라 실제 캔버스를 지우고 다시 그린다. 부분 소거의 구현 가능성 근거이자 가까운 선행이다. 본 안은 생성형 그림 협업을 복제하지 않으며, AI가 소거할 의미 단서를 고르는 제한된 적대 게임이다.
- [iNNk](https://blogit.itu.dk/pxlab/projects/innk/)는 사람이 그림으로 비밀 단어를 전달하면서 AI가 맞히지 못하게 하는 게임이다. 본 안에서는 AI가 정답을 이미 알고 있으며 원본을 지워 전달을 막는다. 인간의 핵심 선택이 ‘분류기를 속이는 그림’에서 ‘손실 뒤에도 전달되는 표현과 복구’로 달라진다.
- [Competitive Drawing](https://github.com/kylesayrs/Competitive-Drawing)은 공유 캔버스의 다른 프롬프트를 신경망으로 판정한다. 스케치 분류를 실제 게임에 쓰는 기술 경로의 근거이며, 지우개 기구나 위의 전달/복구 규칙을 구현한 것으로 읽지 않았다.

동일한 물리 소거·전달 게임은 조사 범위에서 확인하지 못했다. 로봇 미술, 그림 분류, 적대적 게임의 원리를 발명했다고 주장하지 않는다.
