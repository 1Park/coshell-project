# N034 WindNegotiator — 내가 조종할 수 있지만 AI는 아직 모르는 배

2026-10-04 · 상태: **VALID — 설계 검토 통과**. 실제 제작·승률·학습 속도 검증 완료라는 뜻은 아니다.

## 한 번의 경기

참가자가 공통 폼 선체에 돛을 잘라 붙이거나 돛의 위치와 각도를 바꾼다. 그 배를 **참가자가 먼저** 팬 세 개의 노브만 조작하여 두 개의 게이트로 통과시킨다. 성공한 배만 AI에게 도전할 수 있다. AI는 같은 배, 같은 시작 위치, 같은 팬 출력 제한에서 짧게 시험한 뒤 같은 경로에 도전한다. 사람은 AI의 실패를 보고 다음 라운드에 돛을 다시 설계한다.

승부는 제한 시간 안에 통과한 게이트 수, 동률이면 통과 시간으로 정한다. 배를 손으로 밀거나 선체에 추진기를 달 수 없다. AI가 배를 전혀 움직일 수 없게 만드는 것이 아니라 **자신은 다룰 수 있는 낯선 운동 특성**을 만드는 것이 사람의 전략이다. 첫 버전은 배 한 대를 번갈아 쓰며, 두 대의 동시 충돌 회피는 제외한다.

사용자는 과학관·메이커 행사 참가자다. 팬 세기를 비교하는 단발 전시를, 자신의 물체 설계로 학습하는 상대에게 도전하는 반복 놀이로 바꾼다. 교육 효과나 장기적인 재미를 검증했다고 주장하지 않는다.

## 왜 물리 장치인가

수조 영상만 분석해서는 참가자가 만든 배에 힘을 가할 수 없다. 팬의 실제 바람, 배의 관성과 회전, 참가자가 붙인 돛의 비대칭이 게임 상태다. VENTUNO Q의 Linux 측이 다음 짧은 구간의 팬 명령을 고르고 MCU가 PWM·회전수·타임아웃을 관리한다. 다음 영상의 운동으로 예측을 갱신한다.

데스크탑도 팬·드라이버·현장 제어기를 추가하면 구현할 수 있다. 특정 Arduino만 가능한 발명이라는 주장은 하지 않는다. 핵심은 카메라 앱으로 대체할 수 없는 **실제 힘을 주고 결과를 되읽는 임베디드 구조**다.

## AI가 실제로 맡는 일

위치·방향·속도·회전 속도·직전 팬 출력에서 다음 운동을 예측하는 작은 신경망을 사용한다. 마커 추적과 게이트 판정에는 고전 영상 처리를 쓴다. 신경망을 붙여 인식량만 늘리지 않는다.

팬 하나를 켰을 때의 효과는 배의 위치, 돛 방향과 비대칭에 따라 달라진다. 목표 위치의 오차만 줄이는 PID로는 팬 간 결합과 이후의 회전을 직접 표현하지 못한다. 소형 모델로 실제 응답을 학습하고, 여러 짧은 명령을 예측해 경로에 유리한 것을 고른다. 물리 시뮬레이터나 대규모 강화학습을 새로 만들 필요는 없다.

**강한 비교군:** 같은 시험 시간과 센서를 사용하는 ① 보트별로 교정한 PID, ② 선형 응답 모델+동일한 예측 제어기, ③ 위치·방향 항을 가진 간단한 매개변수 물리 모델. 고정 출력이나 무작위 바람만 이겨서 AI의 이득이라고 하지 않는다. 변경된 돛에서의 재교정 횟수·게이트 완주율·완주 시간을 비교한다. 학습의 이득은 구조상 타당한 가설이며, 측정된 결과는 아직 없다.

## 부품과 데이터

- 50–70cm 정도의 얕은 수조, 작은 공통 선체, 참가자가 바꾸는 돛과 부착 위치.
- 보호망을 둔 PWM 팬 세 개, 각 드라이버, 별도 전원, 노브 세 개. GPIO에서 팬 전력을 공급하지 않는다.
- 상부 USB 카메라와 선체의 방향 마커. VENTUNO Q 한 대. 액추에이터 추가 확보가 필요하다.
- 자동 라벨: 명령 시점의 상태와 짧은 시간 뒤의 실제 이동량. 사람이 정답 방향을 매번 붙이지 않는다.
- 시작 데이터는 몇 가지 돛으로 수집한 궤적. 현장에는 학습에 쓰지 않은 돛 모양·부착 위치를 넣는다. 연속 프레임을 무작위로 섞어 검증하지 않고 궤적/돛 단위로 분리한다.
- 작은 MLP를 CPU에서 먼저 실행한다. NPU 변환 성공을 임계 경로에 넣지 않는다.

## 가능한 범위와 순차 경로

아래 시간은 작업 견적이며 행사에서 보장된 연속 작업 시간이 아니다.

1. 팬 출력과 정지·회전수 확인: 약 2–3시간.
2. 수조 배치, 사람의 두 게이트 조종, 위치 추적: 추가 3–5시간. **첫 중단 기준:** 기본 선체와 평범한 돛에서도 사람이 반복해서 두 게이트를 통과하지 못하면 모델 작업 전에 배치/경로를 고친다. 이를 고치지 못하면 해당 구현은 중단한다.
3. 자동 궤적 수집, 선형 모델과 소형 신경망 학습: 추가 3–4시간.
4. 예측 제어와 실제 루프 통합: 추가 3–4시간.
5. 새 돛으로 비교 경기와 발표: 추가 2–3시간.

선체 제작·제어·데이터 수집을 세 사람이 모두 동시에 끝낼 수 있다고 계산하지 않았다. 기능 범위는 한 배, 두 게이트, 세 팬, 돛 변경이다. 완전한 자동 항해, 임의 선체 복원, 유체 해석은 포함하지 않는다.

## 가까운 선행과 실질적인 차이

- [Sailing Science Center의 전시](https://www.sailingscience.org/exhibits): 실제 바람과 참가자가 만드는 배를 이용하는 전시가 있다. 팬으로 돛 단 배를 움직이는 물리는 새 발견이 아니다. 본 안의 차이는 사람의 조종 성공을 참가 조건으로 삼고, 같은 물체를 AI가 새로 학습하는 설계 대결이다.
- [Stevens의 2025 자율 보트 경기](https://www.stevens.edu/news/how-a-self-driving-boat-took-victory-laps-at-the-2025-stevens-gallois-robotics-competition): 자율 보트 경기는 이미 있다. 본 안은 탑재 추진기를 달고 자율 주행하는 배를 만드는 경쟁이 아니라, 참가자가 만든 수동 물체에 외부 팬으로 작용하는 상대와 겨루는 경기다.
- [공간 문법과 신경망을 이용한 돛배 설계·행동 최적화](https://doi.org/10.1115/1.4044398): 배 설계와 학습 제어의 결합도 기존 연구다. 이 논문은 시뮬레이션에서 설계/행동을 최적화한다. 사람의 실제 조종을 자격 조건으로 하는 탁상 대결과는 사용 흐름이 다르다.
- [확률적 동역학 모델을 이용한 표본 효율적인 제어 연구](https://arxiv.org/abs/1805.12114): 학습된 동역학과 계획을 결합하는 기술 경로의 근거다. 이 연구가 본 수조나 보트의 성능을 입증한 것은 아니다.

기능 중심·반증 중심 검색에서 위 경기 흐름의 같은 구현은 확인하지 못했다. 전 세계에 없다는 보증이나 특허 판정은 아니다. 검색어와 결과 메타데이터는 누적 검색 기록에 보존한다.
