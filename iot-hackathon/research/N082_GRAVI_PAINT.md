# N082 GraviPaint — 실제 유동화의 구도를 보존하는 경사대

2026-10-05 · **REJECTED — 최종 설계 심사 제외.** 최초 OPEN 검토와 후속 조사 이력을 보존한다. 아래는 설계안이며 물감 실험·모델 학습·보드 실행을 하지 않았다.

## 사용 장면과 결과

아크릴 유동화를 만들 때 물감을 캔버스 끝까지 보내다가 마음에 들었던 가운데 무늬가 늘어나거나 밖으로 흘러갈 수 있다. 사용자가 현재 무늬 중 보존하고 싶은 부분과 추가로 채울 부분을 고르면, 장치가 작은 캔버스를 두 축으로 기울여 충전과 무늬 변형 사이의 절충을 수행한다. 결과는 화면에 생성한 이미지가 아니라 실제 물감으로 남는 작품이다.

그림 전체를 사진처럼 재현하거나 모든 보존 조건을 만족한다고 약속하지 않는다. 두 축의 전역 경사만으로 서로 다른 물감 영역을 독립적으로 움직일 수 없기 때문이다. 사용자가 지정한 목표가 충돌하면 이를 드러내야 하며, 아무 일도 하지 않고 정지만 한 결과를 성공으로 세지 않는다.

## 물리 구성과 AI 역할

15–20cm 판, 중앙 관절과 서로 직교하는 두 서보/링크, 실제 판의 IMU, 판 위 USB 카메라, 캔버스 고정 장치, 받침 트레이, 별도 모터 전원, VENTUNO Q를 가정한다. MPU가 영상 추적·유동 응답 모델·짧은 경사 계획을 수행하고 MCU가 실제 각도/속도 제한과 구동·정지 상태를 처리한다. 센서 액세서리만으로 완성되는 안은 아니다.

실제 경사와 영상의 물감 전면/무늬 이동 → 다음 짧은 경사에서의 이동 예측 → 두 모터의 실제 경사 변경 → 새 영상과 IMU로 재측정한다. 데스크탑과 카메라만으로 실제 중력 방향을 바꿀 수 없다. 데스크탑에 같은 액추에이터와 제어기를 추가하면 구현할 수 있다는 점은 인정한다. Arduino만 가능한 물리 원리를 주장하지 않는다.

고정 조명 아래 서로 구별되는 2–3색과 한 종류의 유동화 물감/바탕 재료에서 시작한다. 색 분리·특징 추적·좌표 보정은 고전 영상 처리로 맡기고, 모델은 최근 이동·경사 이력에서 다음 이동을 예측한다. 물감 점도나 내부 두께를 한 장의 RGB 영상만으로 정확히 알아낸다고 하지 않는다.

초기 모델 후보는 8개 무늬/전면 기준점의 위치·최근 속도, 실제 두 경사, 경사 명령 이력, 경과 시간을 입력으로 하는 작은 MLP다. 출력은 0.5–1초 뒤 기준점 변위다. 기구 자체 움직임은 판 모서리 기준점으로 제거해야 한다. 학습 라벨은 나중 영상에서 얻되 특징 추적이 실패한 구간은 학습에서 제외한다. 데이터 분할은 인접 프레임 무작위 분할이 아니라 별도 물감 부음/판 단위여야 한다.

이 후보는 모델 구조가 작다는 이유만으로 학습 데이터가 충분하다고 가정하지 않는다. 같은 외형·속도라도 아래 물감 두께와 혼합 이력 때문에 이후 응답이 다르면 최근 이력만으로 상태를 구별하지 못할 수 있다. 이 경우 G08 실패다.

## 강한 비교군과 남은 반론

1. 사람이 조이스틱으로 같은 경사대를 조작한다.
2. 현재 전면 속도를 보며 목표 반대쪽으로 기울이는 피드백 제어를 쓴다.
3. 매번 갱신하는 선형 경사→유동 모델에 동일한 예측·목표 함수를 붙인다.

학습 모델은 다중 무늬의 서로 다른 속도와 이력에 따른 응답에서 이득이 있어야 한다. 고정 속도나 무작위 경사만 이기도록 비교하지 않는다. 간단한 선형 모델이 같은 무늬 보존/충전을 달성하면 AI가 주변 기능으로 남으므로 제외한다.

확장하고 싶은 구도와 보존할 무늬의 지정은 실제 유동화 작업과 연결되지만, 그 목표를 적는 것만으로 기계가 좋은 선택을 할 수 있음이 입증되지는 않는다. 사람이 경사대를 직접 돌리는 것보다 절충이 나아지는 장면이 남아 있는지 확인해야 한다.

## 범위와 순차 작업 견적

기구/기울기 추적 3–4시간 → 실제 물감 영상 추적 1–2시간 → 여러 초기 배치의 물감 부음·경사 기록·판 교체 2–3시간 → 선형 비교군/작은 모델 2–3시간 → 통합·최종 작품 비교 2–3시간. **10–15시간이라는 견적은 측정값이 아니다.** 인접 프레임 수천 장이 곧 수천 번의 독립 실험이라는 계산을 하지 않는다.

초기 중단 기준은 두 가지다. 첫째, 기울기를 바꿔도 시연 시간 안에 관측 가능한 흐름이 없거나 너무 빨리 흘러 제어 여지가 없다면 물감/각도 조정을 한 차례 한 뒤 재판정한다. 둘째, 독립적인 부음에서 짧은 이동 예측이 선형 비교군보다 유용하지 않다면 목표 달성에 필요한 AI 근거가 부족하다. 범위를 물 공을 가운데 두는 게임으로 바꾸어 통과시키지 않는다.

직접 결과는 최종 캔버스의 목표 영역 충전율, 사용자가 고른 무늬의 상대 형태 변화, 밖으로 잃은 무늬/물감이다. 모델 예측 오차만 낮아진 것을 좋은 작품이나 사용자 수고 감소와 같다고 하지 않는다.

- [Cal Poly의 도료 처짐·평탄화 예측 연구](https://digitalcommons.calpoly.edu/theses/2205/)는 배합과 유변학 측정값을 이용한 예측을 다룬다. 영상만으로 같은 예측 성능을 얻을 수 있다는 증거로 사용하지 않는다.
- [The Pourtrait](https://devpost.com/software/the-pourtrait)는 전자 컵의 기울임을 디지털 마블링 생성으로 연결한 공개 해커톤 프로젝트다. 실제 물감이 놓인 판을 능동적으로 기울이지 않는다.
- [Pratt의 Painterly Urbanism](https://www.pratt.edu/news/building-bridges-at-the-seoul-biennale/)은 실제 푸어링과 로봇 팔의 나이프 작업, 생성 이미지의 조합이다. 본 안과 같은 무늬 보존 피드백 경사 제어를 했다는 설명은 확인하지 못했다.
- 자동 주탕·붓질·디지털 PaintBot 검색 결과는 실제 같은 사용 흐름인지 구분했다. 디지털 캔버스의 brush tilt를 실물 캔버스 경사 제어로 오인하지 않았다.

## 현재 체크리스트 판정

### 14차 후속 근거

[중력에 의한 액체 막의 최적 경사 제어 연구](https://arxiv.org/abs/1901.06028)는 두 축 표면 운동으로 액체를 퍼뜨리는 알려진 모델을 제공한다. 그러나 이 연구는 막 두께와 유변학을 포함한 모델 기반 최적화다. 여덟 개 영상 기준점만으로 같은 상태를 얻는다는 근거가 아니며, 학습이 없는 강한 물리 비교군으로도 고려해야 한다.

[GOLDEN 제조사 안내](https://goldenartistcolors.com/resources/color-pouring-mediums-gloss-and-matte)는 실제 기울임으로 유동화 무늬를 늘리는 작업을 설명한다. 또한 Gloss 혼합물의 기포 안정화 대기, Matte의 즉시 사용 가능성, 건조 중 수평 유지와 여러 날의 경화 시간을 구분한다. 데이터 수집 때마다 완전 건조를 기다릴 필요는 없지만, 젖은 시연 결과를 경화가 끝난 작품의 형태/내구성까지 검증한 것으로 표현하면 안 된다. 이 근거가 G06/G08의 미해결 조건을 없애지는 않는다.

G01: 기존 수채화 수분 제어 N026/N040, 자동 이젤 N060, 학습 제어 경기 N034와 대조했다. 숨은 수분 추정과 사용자 의도 추측은 이 안의 입력에서 제거했다. 이것이 곧 G06/G08 해결을 뜻하지 않는다.

G06/G08/G09/G13은 OPEN이다. 사용자 작업과 물리 원리가 N034와 다르지만 학습 동역학 제어를 공유하므로 G14도 최종 선정에서 확인해야 한다. 아직 14개 PASS로 기록하지 않는다.

### 15차 후속 확인 — OPEN 유지

[FluidLab](https://fluidlab2023.github.io/index.html)은 복잡한 유체 상호작용의 시뮬레이터와 실제 얼음과자·라테 아트·혼합 등의 실행을 제시한다. [점성 제트로 글씨를 쓰는 연구](https://doi.org/10.1039/D3SM00177F)는 학습한 노즐 이동을 실제 점성 제트에 적용했다. 따라서 실제 유체를 학습/최적화로 조작한다는 원리 자체가 미확인이라고 할 수는 없다.

다만 두 연구는 현재 후보의 RGB 기준점 여덟 개가 필요한 도막 상태를 충분히 제공한다는 증거가 아니다. 목표 작품의 무늬 보존과 독립적인 물감 부음에서의 모델 일반화도 별도로 남는다. 이 일반 근거를 이유로 G06/G08/G09/G13을 PASS로 바꾸지 않았다.


## 2026-10-05 최종 판정 — 제외

실제 경사 제어는 IoT 조건을 충족하며, 물감이 기울기에 따라 흐른다는 물리 원리도 문제가 아니다. 제외 이유는 이 작업의 핵심인 **무늬를 덜 망가뜨리면서 다른 영역을 채우는 선택을, 제안한 관측과 짧은 학습으로 할 수 있다는 근거가 부족하다**는 점이다. 실험 실패나 물리적 불가능 판정은 아니다.

- **G06:** 동일 센서의 온라인 선형 모델·물리 모델과 비교할 항목은 정의했지만 학습이 필요한 조건과 그 조건에서 구현 가능한 데이터 경로를 함께 확보하지 못했다. 일반적인 비선형 유체라는 설명만으로 작은 MLP의 추가 가치를 통과시키지 않는다.
- **G08:** 무늬 위치·속도 여덟 개가 다음 경사에 필요한 도막 상태를 충분히 요약한다는 근거가 없다. 짧게 흔들어 능동 탐색하는 방안도 검토했지만 그 과정 자체가 보존하려는 무늬를 바꾸며, 상태 식별과 작품 손상의 절충이 해결되지 않았다.
- **G09/G13:** 배합·양·초기 배치를 엄격하게 고정하면 구현 부담은 줄지만 단순 교정 제어 대비 AI 이유가 더 약해진다. 반대로 깊이 계측이나 정밀 유체 시뮬레이터를 붙이면 센서 교정·재료 모델링·실물 검증이 새 직렬 작업이 된다. 둘 중 하나를 해결된 것으로 가정해 통과시키지 않는다.

마지막으로 [액체 막 최적 제어 논문](https://arxiv.org/abs/1901.06028)과 [FluidLab](https://fluidlab2023.github.io/index.html)을 재확인했다. 전자는 물리 모델 기반 경사 최적화, 후자는 복합 유체 시뮬레이션과 일부 실물 실행의 근거다. 어느 쪽도 현재 8개 RGB 기준점 설계의 관측 충분성이나 소량 실측 학습을 직접 검증하지 않는다.

기구의 존재 가능성과 구체적인 해커톤 구현 경로를 구별해 **현 설계는 최종 제외**한다. 물감 실험·학습·보드 실행은 수행하지 않았다. 사용자 요청에 따라 이 후보의 파생안이나 새 후보는 추가 탐색하지 않는다.
